1. OVERVIEW

  • Product Name & Tagline: Sambhav Project Management System (SPMS) - "Streamlining teams, time, and tasks in one unified hub."
  • Type of Project: Enterprise SaaS Web Application
  • Background / Context: Managing employees, tracking projects, and reviewing timesheets were highly disconnected processes. Relying on spreadsheets and email chains resulted in poor project visibility, fragmented administrative oversight, and severe inefficiencies in approving timesheets. SPMS was built to consolidate these pillars into one role-based ecosystem.
  • Goal / Objective: Centralize enterprise operations to achieve complete project tracking visibility, streamline employee data management, automate timesheet submissions and approvals, provide robust activity monitoring, and enforce strict role-based administrative control.

2. PROBLEM STATEMENT

  • What problem exists today: Disconnected project tracking, heavily manual employee onboarding and management, lack of centralized visibility across the organization, significant difficulties tracking and approving daily timesheets, and poor auditability of critical system events.
  • Who is affected: Administrators, Reporting Managers, Employees, and Project Stakeholders.
  • Why current solutions fail: Spreadsheets are prone to human error and data loss. Email-based tracking lacks structure and transparency. Manual timesheet approvals create bottlenecks. A lack of accountability in disparate tools prevents leadership from making data-driven decisions.

3. SOLUTION WE PROVIDE

  • What we are building: A centralized project management platform delivering a unified experience for the entire organization.
  • How it solves the problem: SPMS integrates Employee Management, Reporting Manager Management, Project Tracking, Timesheet Management, and Activity Logs into a single pane of glass with granular Administrative Oversight and strict Role-Based Access Control.
  • Key differentiators: A deeply integrated ecosystem where employee hierarchies seamlessly map to project assignments and daily timesheet constraints. Zero fragmentation between tracking hours, viewing enterprise templates, and monitoring real-time system audit logs.

4. STAKEHOLDERS

  • Product Owner: Platform Steering Committee
  • Technical Team: Enterprise Architecture Group
  • Development Team: In-house SPMS Engineering Team
  • Operations Team: Internal HR and IT Operations
  • Business Management: Executive Leadership and Directors
  • End Users: Reporting Managers, Employees, and Interns

5. USER ROLES

  • Super Admin: Full system access, capable of managing all users, templates, projects, configuring global settings, and viewing full audit logs.
  • Admin: Administrative operations including managing employees, projects, and overseeing timesheet approval queues.
  • Reporting Manager: Project and team oversight, capable of viewing assigned projects and approving/rejecting direct reports' timesheets.
  • Employee: Project participation, maintaining daily To-Do lists, downloading master templates, and submitting daily timesheets.

6. REQUIREMENTS

Functional Requirements

  • Authentication: Secure Login and Logout, JWT Session Handling, and strict Role-Based Access Control protecting all routes.
  • Employee Management: Capable to Create, Edit, Delete, and View detailed employee profiles and assignments.
  • Reporting Manager Management: Ability to Create, Assign, and Manage hierarchal Teams.
  • Project Management: Create and Edit Projects, handle Team Assignment, track Project Details, Status Tracking, Timeline Tracking, and secure Document Management (S3/R2).
  • Timesheet Management: Create and Submit consolidated daily Timesheets. Managers can Review Timesheets (Approve/Reject) with mandatory feedback. System maintains Historical Tracking.
  • Activity Logs: System-generated Audit Trail recording all User Actions and providing Administrative Monitoring capabilities.
  • Dashboard: Real-time Metrics, Insights, and Operational Visibility widgets summarizing company performance.
  • Templates: Super Admin capabilities for Template Creation and Template Management; employee access for viewing/downloading.

Non-Functional Requirements

  • Performance: Fast Page Load Times utilizing optimized React state to prevent re-render thrashing. API Response Times must be highly optimized.
  • Security: Data encrypted in transit. Role-based endpoints preventing IDOR. Secure presigned URLs for all document access.
  • Scalability: Stateless backend architecture supporting seamless vertical and horizontal scaling.
  • Availability: Designed for 99.9% uptime, accessible securely from modern web browsers.
  • Maintainability: Clean, modular component architecture ensuring rapid feature iteration and easy onboarding for future developers.
  • Responsiveness: Fluid UI adapting seamlessly to desktop, tablet, and mobile web viewports.

10. RISKS & DEPENDENCIES

Risk / Dependency Impact Mitigation Strategy
Scope Expansion High: Will delay the MVP launch date and exhaust budget. Strictly enforce the PRD sign-off. Relegate unapproved features (Payroll, Face ID) to Future Roadmap.
Infrastructure Dependencies Medium: S3/Database outages can halt application workflow. Implement robust cloud architecture with multi-AZ redundancy and automated DB backups.
User Adoption High: Lack of adoption renders timesheet data useless. Provide comprehensive onboarding, intuitive UI, and mandate daily usage via management policy.
Data Quality Medium: Incorrect timesheet logging damages project analytics. Enforce mandatory manager review and feedback loops to reject flawed submissions.
Security Risks High: Unauthorized access to enterprise artifacts or PII. Implement strict RBAC, JWT expirations, and audit logs for continuous monitoring.
Scaling Challenges Medium: System lag during end-of-day timesheet submission spikes. Optimize database indexing, implement aggregated API endpoints, and utilize connection pooling.

11. SUCCESS METRICS (KPIS)

  • Adoption: Achieve high Active Users daily count and 100% Employee Participation within the first 30 days.
  • Productivity: 95%+ Timesheet Completion Rate ensuring Project Tracking Accuracy.
  • System Performance: Consistently low Page Load Times and highly optimized API Response Times under load.
  • Administrative Efficiency: Measurable Reduction in Manual Work compared to legacy spreadsheet methods.
